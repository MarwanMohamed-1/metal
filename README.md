# Hegazy Metal — Angular website

A standalone Angular application using NgRx for language selection, service selection and the quote-request UI. The company overview, products, project references and contact information are based on the supplied Hegazy Metal company profile. Product specifications and compliance are described as project-specific and must be confirmed before being published as technical commitments.

## Run locally

Requires Node.js and npm. From this folder run:

```bash
npm install
npm start
```

Open the local URL printed by Angular CLI (usually `http://localhost:4200`).

## Build

```bash
npm run build
```

## Brand assets

- `src/assets/hegazy-metal-logo.png` — extracted company logo with transparent background.
- `src/assets/hegazy-metal-icon.png` — isolated emblem.
- `src/assets/favicon.png` — browser tab icon.

The navbar logo has a subtle 3D flip animation, with reduced-motion preferences respected by the global stylesheet.
